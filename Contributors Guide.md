# Nigeria AI Collective Repository — Contributors Guide

Welcome to the **Nigeria AI Collective Repository**, our community initiative to document, promote, and connect the entire AI development landscape in Nigeria.

Your contributions are vital! They help showcase the creativity, innovation, and research leadership emerging from Nigeria’s growing AI ecosystem.

Thank you for helping make AI knowledge open, inclusive, and accessible to all.

---

## 1. Ways to Contribute

You can contribute to this repository in the following key areas:

| Type | Description | Example |
| :---: | :---: | :---: |
| **Research Contributions** | Add peer-reviewed papers, preprints, whitepapers, or technical reports either authored by Nigerians or focused on AI in Nigeria. | “Evaluating Machine Translation for African Languages” (ICLR 2025) |
| **Startup / Organization** | Add verified Nigerian AI startups, innovation hubs, or research centers. | EqualyzAI, Awarri, NCAIR, NITDA-AI Collective |
| **Open-Source & Datasets** | Provide links to datasets, APIs, or AI tools developed by Nigerian researchers or teams. | Igbo API, AfroSLM, MasakhaNER 2.0 |
| **Events & Hackathons** | Document ongoing or past events that strengthen the Nigerian AI community. | Zindi Africa Challenges, DSN Bootcamp, NCAIR Hackathon |
| **Awards & Recognition** | Highlight individuals or teams recognized for excellence in AI research, ethics, or innovation. | AI4Good Nigeria Awards 2025 |

## 2. How to Submit Your Contribution

There are **two ways** to contribute. Choose the one that suits you best:

| | **Option A: Contribution Form** | **Option B: Pull Request** |
| :--- | :--- | :--- |
| **Best for** | Non-developers, researchers, policymakers, students, anyone | Developers comfortable with Git and Markdown |
| **What you need** | A free GitHub account | A GitHub account and basic Git knowledge |
| **What you do** | Fill a short form | Edit the `README` yourself |
| **Who adds the entry** | A maintainer adds it for you | You add it; a maintainer reviews and merges |

### Option A: Submit Through the Contribution Form (no coding needed)

1.  **Open the form**
    Click here: [**✦ Submit a contribution**](https://github.com/aicollectiveng/Nigeria-AI-Repository/issues/new?template=contribution.yml)
    (or go to the **Issues** tab → **New issue** → **Submit a contribution (no coding needed)**).

2.  **Sign in to GitHub**
    If you don't have an account, [create one for free](https://github.com/signup). It takes about a minute.

3.  **Fill in the form**

    | Field | What to enter |
    | :--- | :--- |
    | **Full name** | How you'd like to be credited |
    | **Email address** | So we can reach you if we have questions |
    | **Affiliation** | Your organisation, university, startup, lab or community (or "Independent") |
    | **Type of contribution** | The section it belongs to, e.g. Dataset, Startup, Published Paper |
    | **Name or title of the resource** | e.g. *NaijaVoices dataset* |
    | **Link** | An official or trusted link |
    | **Your contribution** | One to three sentences on what it is and why it matters for AI in Nigeria |

4.  **Click "Create"**
    Your submission is saved as an issue labelled `contribution`. A maintainer will review it, add it to the repository and close the issue with a thank-you note. You'll get GitHub notifications along the way.

> **Privacy note:** GitHub issues are public. Everything you enter in the form, including your email address, can be seen by anyone. If you'd rather keep your email private, contact us through the channels in [Section 7](#7-need-help).

### Option B: Submit a Pull Request (for developers)

Follow these five steps to submit your entry:

1.  **Fork the Repository**
    Click the **Fork** button at the top right of the Repository page.

2.  **Create a New Branch**

    ```bash
    git checkout -b add-your-name-or-project
    ```

3.  **Edit the Relevant Section**
    Add your entry to the correct section of the `README` (e.g., “AI Startups” or “Datasets”). Please use the example formats below to ensure consistency.

4.  **Commit and Push**

    ```bash
    git commit -m "Added [brief description of your contribution]"
    git push origin add-your-name-or-project
    ```

5.  **Submit a Pull Request (PR)**
    Go to your fork, click **“Compare & Pull Request,”** and provide a brief explanation of what you added and why it's relevant.

## 5. Contribution Principles

Before submitting, please ensure your entry adheres to these principles:

* **Is accurate and verifiable** (use official or trusted links).
* **Fits the repository’s structure and markdown format.**
* **Reflects AI-related activity** in or connected to Nigeria.
* **Respects the Code of Conduct** (be kind, professional, and collaborative).
* **Avoids promotional, duplicate, or off-topic content.**

---

## 6. Code of Conduct

This repository adheres to the [**Contributor Covenant Code of Conduct**](https://www.contributor-covenant.org/).

All community members are expected to:

* Be **respectful and inclusive.**
* **Value diverse perspectives and expertise.**
* **Report any issues or misconduct** to maintain a positive, safe space for collaboration.
